# HireMate

HireMate is an AI-powered job application assistant that helps users improve resumes and match them with relevant job opportunities.

## Features

- Resume Upload
- Resume Analysis
- AI Suggestions
- Job Matching
- React Frontend
- FastAPI Backend

## Tech Stack

Frontend:
- React
- Vite

Backend:
- FastAPI
- Python

Status:
🚧 Project is currently under development.
